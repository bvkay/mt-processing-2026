# Tests

This page lists the test files of `tests/`, grouped by subject, with what
each one checks and the command that runs it.

## Running a test

Each test file is run on its own (no pytest runner wired up yet); the smoke test
needs an offscreen Qt platform and writes its screenshots to
`surveys/curnamona_cube/work/qc/gui_*.png` (gitignored; regenerate them by
running it).

Run a test from the repository folder in the `bbmt-2026` environment. A
command that starts with `QT_QPA_PLATFORM=offscreen` opens the window
without a screen.
